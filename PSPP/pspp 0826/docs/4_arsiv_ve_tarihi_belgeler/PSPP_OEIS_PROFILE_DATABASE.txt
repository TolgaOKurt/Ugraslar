SECTION 1: MATHEMATICAL FOUNDATIONS - DELTA VS. CUMULATIVE REPRESENTATIONS
--------------------------------------------------------------------------------
In the Postage Stamp Problem with Subtraction (PSPP), the goal is to find
a set B of n strictly positive integers: B = {b1, b2, ..., bn} with
1 <= b1 < b2 < ... < bn.

1. Cumulative Sequence (Set B - Stamp Coordinates):
   Represents the physical values on the integer number line: [b1, b2, ..., bn].
   Using addition and subtraction of at most two stamps, the spanning set S(B) is:
     S(B) = {bi | 1 <= i <= n} U {bi + bj | 1 <= i <= j <= n} U {|bj - bi| | 1 <= i < j <= n}
   The score M(B) is the largest integer M such that {1, 2, ..., M} is completely
   covered without any gaps: {1, 2, ..., M} is a subset of S(B).
   a(n) is the maximum achievable M across all valid sets of size n.

2. Delta Sequence (Step Increments):
   To analyze structural patterns, modular lineages, and prune search trees,
   sets are represented by their consecutive step differences delta = [d0, d1, ..., d(n-1)]:
     d0 = b1
     di = b(i+1) - bi  (for i >= 1)
   The cumulative set B is reconstructed via prefix sums:
     b1 = d0
     b2 = d0 + d1
     bk = d0 + d1 + ... + d(k-1)
     bn = max(B) = sum(delta) = d0 + d1 + ... + d(n-1)

3. Why the Delta Representation?
   - Elimination of Coupled Monotonic Constraints:
     In the cumulative domain, one must strictly enforce the chain 1 <= b1 < b2 < ... < bn.
     Every variable b_k is tightly coupled to its neighbors. In contrast, the delta
     representation decouples this into independent local lower bounds: d_i >= 1 for all i.
     Any positive integer vector delta unconditionally guarantees a strictly increasing,
     sorted cumulative set B via prefix sums, eliminating sorting overhead.
   - Search Space Freedom & Mutation Invariance:
     In combinatorial backtrack search, local mutations, or heuristic exploration,
     altering or swapping delta elements d_i never violates the ordering of B.
   - Direct Sub-Array Sum Mapping:
     Every pairwise difference |bj - bi| (for j > i) maps directly to a contiguous
     sub-array sum of delta:
       bj - bi = di + d(i+1) + ... + d(j-1)
     This links PSPP directly to additive combinatorics and contiguous difference bases.
   - Modular Periodic Compression:
     In linear families, long arithmetic progressions [12, 24, 36, 48, 60, ...] collapse
     into constant runs [12, 12, 12, 12, 12, ...], enabling compact Run-Length Encoding
     and parameterized multi-thousand-element expansions.
   - Modular Residue Completion Tails:
     Terminal delta elements act as an optimal residue filter, systematically closing
     arithmetic parity gaps and modular remainder voids.
   - Two-Sided Difference Spanning:
     Every large step S bridges elements both forward (+k via addition) and backward
     (-k via subtraction), doubling spanning density relative to purely additive bases.
